# R4ezka

**R4ezka** — неофициальный Android-клиент для сайта Rezka TV.

Приложение предоставляет удобный мобильный интерфейс для просмотра каталога, поиска фильмов и сериалов, управления избранным и историей просмотра, а также воспроизведения контента во встроенном плеере.

## Возможности

- 🎬 Каталог фильмов и сериалов
- 🔎 Поиск по каталогу
- 📺 Просмотр информации о фильмах и сериалах
- ▶️ Встроенный видеоплеер
- ⭐ Избранное
- 🕘 История просмотра
- 📱 Интерфейс, адаптированный для Android
- 🌙 Современный интерфейс на Jetpack Compose

## Технологии

Проект разработан для Android с использованием:

- **Kotlin**
- **Jetpack Compose**
- **Android SDK**
- **Gradle**
- **Kotlin DSL**

## Требования

Для разработки и сборки проекта потребуется:

- Android Studio
- JDK
- Android SDK
- Git

## Сборка

Клонируйте репозиторий:

```bash
git clone https://github.com/ran4erep/R4ezka.git
cd R4ezka
```

После этого откройте проект в Android Studio и дождитесь завершения синхронизации Gradle.

Для сборки debug-версии из терминала:

```bash
./gradlew assembleDebug
```

Готовый APK будет находиться в:

```text
app/build/outputs/apk/debug/
```

## Установка

Собранный APK можно установить непосредственно на Android-устройство.

Для установки через ADB:

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

Перед установкой APK вручную убедитесь, что на устройстве разрешена установка приложений из неизвестных источников.

## Структура проекта

Основная часть приложения находится в каталоге:

```text
app/
```

Основные Gradle-файлы находятся в корне репозитория:

```text
build.gradle.kts
settings.gradle.kts
gradle.properties
```

## Статус проекта

Проект находится в разработке.

Функциональность и интерфейс могут изменяться между версиями.
